# MK8DX QuickScore 0.8.0 / TypeSafe Jev API

OBSのゲーム映像からリザルトを検出し、名前の先頭文字をJev APIで選択してチーム得点を計算します。初回の名前見本登録やローカルGPUモデルは不要です。従来の出力形式・score.txt・Discord BotトークンとチャンネルIDによる手動送信を維持します。

## 操作

1. OBSを終了し、展開した配布フォルダーのinstall.cmdを管理者として実行します。既存プラグインはバックアップされます。
2. OBSの「ドック」→「MK8DX QuickScore」を開きます。
3. 元の16:9ゲーム映像、形式（2v2 / 3v3 / 4v4 / 6v6）、タグを設定します。一番左のタグが自チームです。A、日本語、記号など任意の先頭文字を使えます。
4. 「Jev API / TypeSafe」のAPIキー欄に入力し「APIキーを保存」を押します。Windows資格情報マネージャーへ保存し、入力欄は空になります。保存だけでは画像を送りません。TYPESAFE_API_KEY環境変数も使用できます。
5. 「Jev APIでリザルトを判定する」をONにして「集計開始」を押します。リザルト以外を3秒映すと待機します。既に結果が表示されている場合は「現在のリザルトを確認」を使います。
6. 初期設定は手動確認です。12人のチームを確認し「確認した内容で集計」を押します。弱い判定は未選択です。「この結果をスキップ」で得点を変えずに進めます。
7. 自動集計は停止中に「検証を通った結果を自動集計する」をONにします。12順位・信頼度・各チーム人数・合計82点を満たした結果だけ加算します。

## 設計

結果検出はCPUの順位・加点記号の画像照合で行い、文字判定から独立しています。安定した同じフレームを保存した後、12人それぞれの名前の先頭144×54pxを2倍に拡大し、順位ラベル付き960×576pxの画像にまとめます。この画像だけを1回アップロードし、各順位の先頭文字を12個のChoice質問で選択します。ゲーム画面全体はAPIへ送りません。

接続先は https://api.typesafe.ai/v1/systemone 、モデルはjev-1.14.0に固定しています。公式の画像対応ヘッダーとmultipart形式を使います。画像参照はstateに一度だけ置き、各質問はそこを参照します。候補は登録タグの先頭の文字単位と「不明」です。

確率0.90以上・confidence 0.90以上・次点との差0.25以上を満たした行だけ選択します。これは実画像での正答率を保証する数値ではありません。濁点・半濁点を区別し、英字の大小文字・同音のひらがなカタカナはチーム間の識別キーとして重複を禁止します。表示文字自体は登録された表記を使います。人数合わせで不足行を埋めません。点数・順位・点差の計算はアプリが行います。

同じ結果への自動リクエストは1回だけです。通信失敗・HTTP 429・不正応答は手動確認へ移り、自動再送しません。通信は最大15秒で打ち切り、停止後の応答は破棄します。「Jev APIでチームを再判定する」は利用者が押した場合だけ再送します。APIはTypeSafeアカウントの利用料金・制限が適用されます。

「Jev APIでリザルトを判定する」をOFFにすると以前のCPU画像照合を利用できます。CPU用の名前見本は手動確認後だけ保存します。Jev APIの判定結果を未確認のまま見本へ追加しません。

## 保存・Discord

設定・履歴は %APPDATA%\obs-studio\plugin_config\mk8dx-quickscore 。検出時の全体PNG・リザルト一覧PNG・情報JSONは同フォルダーのcapturesへ保存します。未確定・スキップ・停止でも画像は残ります。「リザルト画像の保存フォルダーを開く」で開けます。

APIキーとDiscord Botトークンは別々のWindows資格情報として保存します。APIキーを設定ファイルや配布ZIPへ含めません。Discordは従来どおり「Discordへ送信」を押したときだけ得点行を送ります。

## ビルドと検証

対応するソースをsourceへ同梱します。build.ps1にOBS SDK、Qt SDK、CppWinrt、BuildDirを指定します。CMakeのQUICKSCORE_TLS_BACKENDには受取先OBSのQtと同じマイナーバージョンのSchannelバックエンドを指定してinstallしてください。配布版のTLSバックエンドはQt 6.11.2、テストしたOBSのQtは6.11.1です。OBS本体のQt DLLは置き換えません。

CTestは7件です。jev-api-testはmultipart送信・12順位の解析・確率検証・重複要求・取消・HTTP 429をテストします。api-dock-testは隔離プロファイルのlibobs D3D映像とテストHTTPサーバーでUIから得点保存まで検証します。追加の実APIモードは最後の引数にキーのファイルパスを指定します。キーそのものを引数にしません。

詳しい実測・検証範囲はTEST-REPORT.mdを参照してください。TypeSafeの画像機能は公式に試験的機能として案内されているため、初期設定の手動確認を残しています。全ての文字・全てのレースでの認識率や一定の応答時間は保証しません。
