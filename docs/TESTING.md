# テスト手順と実測

## APIを使わないテスト

ビルド後、Qt SDKのbinをPATH、pluginsをQT_PLUGIN_PATHへ設定するか、CMakeが用意するCTest環境を利用する。

```powershell
ctest --test-dir .\build --output-on-failure
```

7件: jev-api-test / scoring-test / vision-test / analysis-test / local-test / capture-test / fast-test。

`jev-api-test --self-test` はローカルHTTPサーバーでmultipart形式、12順位のマッピング、不正確率、回答欠落、弱いconfidenceの保留、重複要求、HTTP 429、停止後の応答破棄を確認する。実際のAPIキーやAPI料金は不要。

`api-dock-test` は別途OBSのlibobs D3Dを起動する統合テスト。実OBSアプリのドック登録や実キャプチャーボードの連続運用とは分けて扱う。ユーザー設定とは別の一時プロファイルを使う。OBS同梱Qtのbinとplatforms、および同じQtマイナーバージョンのTLSプラグインを使う。SDKのqwindowsプラグインとOBSのQt DLLを混ぜない。

## 実APIによる画像検証

APIは有料。以下は明示的に実行したときだけ通信する。スクリーンショットとキーはリポジトリ外へ保存する。公開用のラベル定義は `tests/fixtures/*.labels.json` にある。画像は配布しない。

```powershell
.\build\jev-api-test.exe C:\private-fixtures\case-a.png `
  .\tests\fixtures\case-a.labels.json C:\private-secrets\jev-key.txt `
  .\reports\case-a.json
```

事前にreportsを作成する。最後のJSONと`.montage.png`に結果・実際の送信画像を保存する。キーを引数そのものに書かない。キーは一時的なWindows資格情報へ保存し、テスト終了時に削除する。実キーを使うスクリプトの標準出力へHTTPヘッダーや環境変数をダンプしない。

labels.jsonは`initials`（登録タグ配列）と`truth`（各順位の0始まりのチーム番号12個）を持つ。型・確率の検証はAPIクライアント、期待するチームとの一致率集計はテストツールの責務。

## トークン削減の比較（2026-11-15）

同じモデル・しきい値で比較した。数字は入力トークンであり、PNGファイルのバイト数ではない。

| 方式 | 画像 | 実2v2画像A | 実2v2画像B |
| --- | --- | ---: | ---: |
| 0.8.0・長い指示と広いROI | 960×576 | 6,163 | 6,165 |
| 指示だけ短縮 | 960×576 | 3,354 | 3,352 |
| 採用案・短い指示と92px幅ROI | 480×448 | 2,459 | 2,462 |
| より小さい試案 | 360×320 | 2,192 | 2,196 |

上記2枚では各案とも12/12一致。ただし360×320の試案は追加の日本語タグ画像で不明行が増えたため採用しなかった。480×448では元方式より約60%削減しつつ、検証セットで誤ったタグへの確定はなかった。

追加検証は実6v6画像3枚、2v2画像から作った3v3/4v4の合成画像2枚、先頭文字を隠した画像2枚。480×448では、実6v6の1枚は11人確定・1人保留、残り2枚は12人一致。隠した行は不明のまま保持した。合成画像での成功は実3v3/4v4の検証を意味しない。

0.8.0の実API単体は約0.4〜0.5秒、実libobs取得→実API→即時の確認操作→得点保存は約1.47秒だった。0.8.1のC++クライアントによる実測は `docs/HANDOFF.md` を参照。ネットワーク、形式、画像、API混雑により変動する。

料金計算は入力トークン数×公式単価。調査時の単価は$0.042/100万入力トークン、出力無料。2,460入力トークンなら約$0.000103、1ドル160円の仮定で約0.017円/結果。アカウントのクレジットや税・為替の請求条件は別途確認する。
